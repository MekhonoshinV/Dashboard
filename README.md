# Финансовый дашборд

Интерактивный веб-дашборд для анализа финансовых данных, построенный с использованием Dash и Plotly.

## Возможности
- **Загрузка данных**: Поддержка загрузки собственных CSV-файлов через веб-интерфейс.
- **Фильтрация**: Выбор категории для детального анализа.
- **Визуализация**:
  - **Линейный график**: Динамика доходов и расходов во времени.
  - **Круговая диаграмма**: Структура расходов по категориям.
  - **Гистограмма**: Распределение прибыли.
  - **Таблица**: Ключевые финансовые показатели (первые 10 записей).
  - **Диаграмма рассеяния**: Корреляция между доходом и прибылью.
  - **Индикатор**: Текущее значение средней прибыли (Gauge).
